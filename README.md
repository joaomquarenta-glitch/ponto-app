# Ponto

Releases da app Android **Ponto** (lembrete para picar o ponto).

Este repositório só serve para publicar o ficheiro de instalação (APK) de cada versão.
A app procura aqui novas versões no botão **Definições › Procurar atualização**.

Para instalar à mão: abre a pasta `apk` e descarrega o ficheiro mais recente.
